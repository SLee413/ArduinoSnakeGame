# Arduino Snake Game
Final project for Embedded Systems Programming Spring 2025

Component Requirements:
- MAX7219
  - DIN - 12
  - CLK - 11
  - CS - 10
- Joystick Module
  - VX - A6
  - VY - A7
- Buzzer
  - Output - 5
 
Libraries:
- https://github.com/wayoda/LedControl/
